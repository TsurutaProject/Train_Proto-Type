# Train Proto-Type

小学生がレール配置ゲームを通して、速さ・時間・距離の関係を体験的に学ぶためのReact製プロトタイプです。

プレイヤーは盤面にレールを配置し、スタートからゴールまでの経路と到着時間を考えます。通常モードに加え、自分で予想時間を入力して実際の結果と比較する見積もりモードも収録しています。

## ゲームの特徴

- 画面上のボタンとクリック・ドラッグで操作
- 電車を動かして駅を選ぶ横長のステージ選択マップ
- チュートリアルとステージ1〜16
- 低速レールと高速レールの配置
- ドラッグによる低速レールの連続配置
- 中継地点、折り返し地点、障害物、混雑区画
- 配置済みレールから最短経路を探索
- 最短経路に応じた直線・曲線レールの自動表示
- 経路上を電車が走るアニメーション
- 予想時間と区間時間の表示
- 通常モードと見積もりモード
- 到着時間と高速レール使用本数による評価
- プレイ結果のブラウザ保存
- 漢字へのルビ表示
- PC・スマートフォン対応

## 遊び方

1. タイトル画面で `START` を押します。
2. ステージ選択マップを左右ボタン、クリック、横スクロールで移動します。
3. 駅を選び、`このステージへ入る`を押します。
4. 低速レールまたは高速レールを選びます。
5. 盤面をクリックまたはドラッグしてレールを配置します。
6. 必要な中継地点や折り返し地点を通ってゴールまでつなぎます。
7. `出発`を押すと、電車が最短経路を走ります。
8. リザルト画面で到着時間と評価を確認します。

ステージ選択画面で現在いる駅をもう一度押しても、そのステージを開始できます。

## ゲームモード

### 通常モード

レールを配置しながら、現在の最短経路に基づく予想時間を確認できます。

### 見積もりモード

レール本数や通過する混雑マスをメモし、自分で予想時間を入力します。正しい時間は出発後に表示され、自分の予想と比較できます。

## レールと時間

| 種類 | 基本速度 | 基本時間 |
| --- | --- | --- |
| 低速レール | 1マス/秒 | 1マスあたり1秒 |
| 高速レール | 2マス/秒 | 1マスあたり0.5秒 |

混雑区画や「のんびり」指定の範囲では、通常とは異なる時間計算になる場合があります。

予想時間に含まれるのは、盤面上に置かれたすべてのレールではなく、条件を満たす最短経路上のレールです。

## ステージ評価

ステージ選択画面には最新のプレイ結果が表示されます。

- 未プレイ
- 目標時間より何秒遅かったか
- 時間以内
- 時間ぴったり
- 高速レール節約
- 最小本数

結果はブラウザの`localStorage`に保存されます。通常モードと見積もりモードの結果は別々に管理されます。

## 必要な環境

- Node.js 24系
- npm
- またはDocker Desktop

## 起動方法

### npmを使用する場合

```bash
npm ci
npm run dev
```

ブラウザで次のURLを開きます。

```text
http://localhost:5173/
```

### Dockerを使用する場合

このリポジトリのフォルダで実行します。

```bash
docker run -it --rm \
  -v "$PWD":/app \
  -w /app \
  -p 5173:5173 \
  node:24-slim \
  sh -c "npm ci && npm run dev -- --host 0.0.0.0"
```

ポート5173が使用中の場合は、ホスト側だけ5174へ変更します。

```bash
docker run -it --rm \
  -v "$PWD":/app \
  -w /app \
  -p 5174:5173 \
  node:24-slim \
  sh -c "npm ci && npm run dev -- --host 0.0.0.0"
```

この場合は`http://localhost:5174/`を開きます。

## 開発用コマンド

| コマンド | 内容 |
| --- | --- |
| `npm run dev` | 開発サーバーを起動 |
| `npm run build` | 本番用ファイルを生成 |
| `npm run preview` | ビルド結果を確認 |
| `npm run lint` | JavaScript・Reactコードを検査 |
| `npm test` | 高速レール評価のテストを実行 |
| `npm run audit:stages` | 全ステージの経路を監査 |
| `npm run audit:stages -- 1` | 指定したステージだけ監査 |

## 開発時の注意

- `node_modules`と`dist`はリポジトリに含めず、必要に応じて再生成します。
- ステージを追加・修正する場合は`src/stages.js`を編集します。
- ステージ変更後は`npm run audit:stages`で到達可能な経路を確認します。
- 時間評価を変更した場合は`npm test`を実行します。
- 表示を変更した場合はPC幅とスマートフォン幅の両方を確認します。
